# 2026-09-28 개발 일지

## 오늘 한 일

1. **저대비 배경에서 캐릭터 몸통 실루엣이 통째로 빠지는 버그 — 원인 규명 + 안전한 안내 기능**
   배경 채우기(`_fill_enclosed_regions`)가 약한 윤곽선 틈으로 캐릭터 내부까지
   침투해버려서, 배경색과 비슷한 파스텔톤 캐릭터의 몸통이 칼선 인식에서
   통째로 빠지는 사례를 여러 실제 파일에서 확인했다. 자동으로 되살리는
   방법을 세 가지(잔여 영역 병합, 배경 색상 모델링, 인페인팅 기반 복원)
   시도했지만 전부 "다른 도안을 잘못 합쳐버리는" 회귀 위험이 있어 보류.
   대신 `core.multi_design`에 `suspicious_regions` 진단 파라미터를 추가해,
   자동 수정은 하지 않되 사람이 확인해야 할 위치만 안전하게 알려주는
   "의심 영역 경고" 기능을 추가했다(기존 호출부는 전부 기본값 유지라
   동작 변화 없음, 새로 넘기는 곳만 켜짐).

2. **경고 항목 클릭 → 미리보기 자동 이동/확대 (수동 확인 보조 기능)**
   "확인이 필요한 영역이 있습니다" 안내창을 모달이 아닌 별도 창으로 바꿔서
   메인 창의 오른쪽 미리보기 캔버스를 가리지 않게 왼쪽 위에 뜨도록 하고,
   좌표가 있는 경고 항목마다 "이 위치로 이동" 버튼을 달았다. 누르면
   미리보기가 그 좌표에 맞춰 적당히 확대되고 스크롤되어 이동한 뒤 주황색
   점선으로 표시된다. 실제 원본 파일로 자동 인식을 돌려 직접 눌러보며
   확인(다른 배율/스크롤 위치에서 다시 눌러도 정확히 재이동하는 것도 확인).
   자동 수정을 하지 않는다는 원칙은 그대로 유지 — 이 기능은 순전히
   "찾아가기 쉽게" 도와주는 보조 기능일 뿐이다.

7. **실제 손 칼선과 대조 → 무테 B안 확정, 도무송 안쪽, 누락 요소 보충** (멍푸: "1.도무송
   직접 선택 후 칼선 종류에 따라 이미지 안쪽으로 칼선 생성. 2.무테 ... 이미지 외곽에
   칼선이 들어가야함. 배경색이 칼선으로 잡히면 안 됨", "테스트 칼선 보면서 대조해")
   - 테스트 폴더의 .ai 파일 칼선 레이어(사람이 직접 그린 칼선)를 읽어 우리 결과와
     요소마다 겹침(IoU)·경계 거리(mm)·개수로 비교하는 스크래치패드 도구를 만듦(커밋 안 함).
   - **무테**: 실제 파일은 칸 한 장이 아니라 **요소마다 그림 안쪽 0.7~1.5mm**로 잘려
     있었음 → 6번의 A안을 버리고 요소마다 안쪽(1.2mm)으로 확정. 실루엣을 먼저 다듬고(열림)
     줄인 뒤(침식) 다시 다듬어(닫힘) 칼선이 그림 밖으로 절대 나가지 않게 함. 너무 가는
     요소는 칼선을 만들지 않고 경고.
   - **도무송(직접 선택/자동)**: 도형을 이미지 **안쪽**에 넣음. 시트 배경색을 이미지 바깥
     테두리에서 추정해 이미지 외곽을 찾고, 그 안에서 재단 여유(3mm, 최소 2mm)만큼 들어간
     영역에 들어가는 가장 큰 원/사각/타원 등을 칼선으로 둠. 실제 카드 칸 칼선(이미지에서
     2.8~3.3mm 안쪽)과 IoU 0.98~0.996, 경계차 0.07~0.34mm. 자동 인식은 카드(칸) 단위.
   - **빈 칸 제외**: 이미지가 없는 칸은 칼선 대상에서 뺌.
   - **누락 요소 보충(자동 보조)**: 칸 가장자리 배경색에서 마술봉처럼 채워(색 경계는 넘지
     않음) 안 채워진 곳을 요소로 보고, 기존 칼선이 없는 것만 추가. 반복 칸에는 같은 모양을
     복사. 줄무늬 배경, 가장자리에 닿은 캐릭터 등 실패 사례를 하나씩 고침. 무테·무테+유테
     자동·①②③의 ③에 자동 적용.
   - **무테+유테 자동 판정**: 흰색/검은색 테두리 선이 있으면 유테(바깥), 없으면 무테(안쪽).
     이전엔 무테 시트를 유테로 잘라 경계차 2.9mm였음 → 1.0mm.
   - **겹치는 무테 칼선 합치기**: 실제로 면적이 겹치는 것만 합침(닿기만 해도 합치는 방식은
     한 파일에서 IoU 0.93→0.63으로 나빠져 되돌림).
   - **칼로 못 자르는 조각 제거**: 평균 폭 0.5mm 미만의 실/점 같은 칼선 조각을 버림(실측:
     옆 박스를 빼고 남은 35x4px 조각, 9x6px 점 2개만 남은 항목).
