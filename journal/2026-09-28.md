# 2026-09-28 개발 일지

## 오늘 한 일

1. **저대비 배경에서 캐릭터 몸통 실루엣이 통째로 빠지는 버그 — 원인 규명 + 안전한 안내 기능**
   배경 채우기(`_fill_enclosed_regions`)가 약한 윤곽선 틈으로 캐릭터 내부까지
   침투해버려서, 배경색과 비슷한 파스텔톤 캐릭터의 몸통이 칼선 인식에서
   통째로 빠지는 사례를 여러 실제 파일에서 확인했다. 자동으로 되살리는
   방법을 세 가지(잔여 영역 병합, 배경 색상 모델링, 인페인팅 기반 복원)
   시도했지만 전부 "다른 도안을 잘못 합쳐버리는" 회귀 위험이 있어 보류.
   대신 `core.multi_design`에 `suspicious_regions` 진단 파라미터를 추가해,
   자동 수정은 하지 않되 사람이 확인해야 할 위치만 안전하게 알려주는
   "의심 영역 경고" 기능을 추가했다(기존 호출부는 전부 기본값 유지라
   동작 변화 없음, 새로 넘기는 곳만 켜짐).

2. **경고 항목 클릭 → 미리보기 자동 이동/확대 (수동 확인 보조 기능)**
   "확인이 필요한 영역이 있습니다" 안내창을 모달이 아닌 별도 창으로 바꿔서
   메인 창의 오른쪽 미리보기 캔버스를 가리지 않게 왼쪽 위에 뜨도록 하고,
   좌표가 있는 경고 항목마다 "이 위치로 이동" 버튼을 달았다. 누르면
   미리보기가 그 좌표에 맞춰 적당히 확대되고 스크롤되어 이동한 뒤 주황색
   점선으로 표시된다. 실제 원본 파일로 자동 인식을 돌려 직접 눌러보며
   확인(다른 배율/스크롤 위치에서 다시 눌러도 정확히 재이동하는 것도 확인).
   자동 수정을 하지 않는다는 원칙은 그대로 유지 — 이 기능은 순전히
   "찾아가기 쉽게" 도와주는 보조 기능일 뿐이다.

3. **개발 이력 감사(audit) — "처음부터 반복된 문제와 놓친 것" 정리**
   처음엔 개발 일지가 2026-08-26 이후로 완전히 끊긴 줄 알았는데, 실제
   컴퓨터의 journal 폴더를 다시 확인해보니 9/9~9/11 일지(23~51차 업데이트)
   가 이 클라우드 작업공간에는 없었을 뿐 실제로는 남아있었다 -- 뒤늦게
   찾아서 이 저장소에도 옮겨왔다(아래 4번 참고). 다만 9/12 이후 오늘까지
   약 2주 반 동안(코드 주석 기준 51차~66차 이상)은 정말로 일지가 없다.
   코드 주석과 README를 시간순으로 훑어 다음을 정리했다.
   - 가장 크고 반복적인 문제: 저대비/약한 윤곽선 경계에서 전경-배경 분리가
     구조적으로 계속 실패하는 문제 — 이름과 증상만 바뀌며(초기 GrabCut
     외곽 확장 → 특정 소품 오탐지 → 캐릭터 얼굴 이중 칼선 → 캐릭터 합쳐짐
     → 이번의 몸통 실루엣 소실) 프로젝트 시작일부터 오늘까지 한 달 넘게
     같은 뿌리에서 재발.
   - "고쳤다"고 전달한 뒤 실사용 검증에서 번복된 사례가 최소 네 건
     (시트 전체 재생성, 소품 칼선 형태, 스모크 예시 안의 실침범 버그,
     자동 축소 기본값) 확인됨.
   - GUI 옵션 팝업이 화면/카드 밖으로 나가는 문제가 최소 6~7차례
     수정되고도 계속 재발해, "여러 번 말했는데 왜 개선이 안 되냐"는
     피드백이 코드 주석에 직접 남아있음.
   - 명시적으로 아직 미해결로 남은 항목: 캐릭터 얼굴 이중 칼선, 특정
     도안들의 캐릭터 합쳐짐 버그, 이번에 다룬 몸통 실루엣 소실, GrabCut
     외곽 확장 경향, 레이어 내보내기 기능 GUI 미연결 등 (자세한 근거는
     세션 대화 기록 참고 — 실제 도안/파일 이름은 여기 남기지 않음).
