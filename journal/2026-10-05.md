## 화이트 레이어 + 칼선 보완 (같은 날 오후)

멍푸: "이제 칼선을 보완하고 화이트 레이어를 만들어주는 기능을 추가 할거야. 좋은 예는 ... 키스컷 마테 좋은 예의
화이트 레이어를 기준으로 인쇄소 가이드, 화이트 레이어 튜토리얼 등 자료 찾아서 만들어. 그리고 확인이나 승인
필요한거는 알림 앱으로 보내"

1. **좋은 예(키스컷 마스킹테이프 롤, 실제 납품 파일) 실측**
   - 레이어 4개: 참고(삭제x) / 칼선 / 도안 / 화이트레이어. 화이트 = "화이트레이어" 레이어의 흰색(C0 M0 Y0 K0)
     면 벡터 159개. 칼선 = 마젠타 100%, 0.5pt 닫힌 선. 도안 = 같은 그림 1장을 롤 길이 방향으로 3번 배치(투명도
     마스크 있음).
   - 화이트 범위: 그림 실루엣과 거의 같음(줄이거나 늘리지 않음). 그림 알파 약 25% 경계로 잡으면 좋은 예 화이트와
     겹침 비율 0.967(50% 경계는 0.938). 작은 점까지 모두 덮고, 그림 안 구멍은 안에 들어가는 원 지름 약 2.1mm
     이하만 메움(2.5mm 이상은 비움).
   - 칼선: 화이트 외곽에서 1.1~1.5mm(중앙값 1.32mm) 바깥으로 고르게. 1.5mm보다 가까워지는 조각은 하나로 합쳐져
     있었다(남은 가장 가까운 간격 1.57mm).
2. **자료 조사**: 인쇄소·튜토리얼 공통 -- 화이트는 별도 레이어(또는 별색)로 지정, 화이트는 그림과 같거나 살짝
   작게(색이 화이트 경계를 덮도록 0.1mm 안팎 줄이는 곳도 있음), 반투명·그러데이션은 화이트 양을 따로 정해야 함.
   좋은 예는 줄이지 않았으므로 기본 0mm, "화이트 줄이기"를 설정으로 둠.
3. **새 기능**(core/white_layer.py, gui/white_layer_ui.py, 왼쪽 패널 "화이트 레이어" 카드)
   - "화이트 레이어 만들기": 그림 출처 우선순위 = .ai 안 이미지의 투명도(SMask) -> 투명 배경 PNG 알파 -> 꽉 찬
     그림이면 지금까지 만든 칼선의 그림 실루엣. 화면에서는 하늘색 반투명으로 겹쳐 보임.
   - "화이트 기준으로 칼선 보완": 키스컷(또는 칼선이 아직 없을 때)은 화이트에서 고르게 띄운 칼선(기본 1.3mm,
     2mm보다 가까워지는 조각은 합침)으로 새로 만들고(기존 칼선이 있으면 먼저 물음), 다른 작업 종류는 기존 칼선은
     그대로 두고 칼선이 없는 그림에만 더함 -- 옆 칼선과 2mm보다 가까워 자동으로 더하기 어려운 곳은 위치만 알림.
   - 저장: PNG는 "_화이트.png"(원본 이미지와 같은 크기, 흰색 면)를 칼선 PNG 옆에, SVG는 같은 파일 안
     "화이트레이어" 그룹(칼선 아래).
4. **함께 고친 문제(칼선 보완)**
   - 같은 그림을 대지에 여러 번 놓은 .ai(마스킹테이프 롤 등)를 SVG로 저장하면 첫 자리에만 칼선이 들어갔다 ->
     놓인 자리마다 똑같이 넣음(core.ai_import.ai_raster_placement "tiles", 크기가 다른 자리는 제외).
   - 격자 레이어가 없는 .ai도 격자 읽기(core.ai_cutline_reader.load_real_grid_cells)가 작업 이미지를 먼저 덮어쓴
     뒤 실패했다 -- 여러 번 배치한 파일이면 작업 이미지가 페이지 전체 그림(기존 칼선·화이트·참고 레이어까지 그려진
     것)으로 바뀌어 자동 인식이 기존 칼선까지 그림으로 봤고 SVG 위치도 어긋났다 -> 격자 레이어부터 확인.
   - 격자가 있고 같은 그림을 여러 번 배치한 파일(여름 스티커형 2개)은 작업 이미지가 페이지 전체 그림이 되는데
     SVG 저장 위치는 첫 자리 기준이라 어긋났다 -> 이 경우 "대지 전체 = 이미지"로 저장.
5. **검증**
   - 좋은 예 롤 전체(3자리), 실제 프로그램 흐름(.ai 열기 -> 키스컷 -> 화이트 -> 칼선 보완 -> SVG 저장) 결과:
     칼선 60개 모두 좋은 예와 일치(겹침 0.984, 경계 차이 0.07mm, 교차·이중·2mm 미만 0), 화이트 겹침 0.970.
     예전 자동 인식(한 자리 기준)은 22개 중 18개 일치·겹침 0.958. 합치는 기준을 1.5mm로 하면 66개 모두 일치(좋은
     예는 1.57mm 간격 6곳을 따로 둠) -- 2mm(지금 기본)로 할지 멍푸 확인 대기.
   - 멍푸 PC 실제 화면: 파일 열기 -> 키스컷 -> 화이트 만들기(34조각, AI 투명도 기준) -> 칼선 보완(20개) -> PNG·SVG
     저장 확인. PC에서 저장한 SVG도 원본 대지와 겹쳐 60개 모두 일치, 화이트 PNG는 작업 공간 계산과 99.75% 같음.
   - 나머지 .ai 10개: 격자 9개 파일의 작업 이미지 크기·격자 칸 수 그대로. 격자 시트(무테 자동 112개)에서 화이트는
     그림 실루엣 기준 115조각, 칼선 빠진 그림 0곳.
   - test_white_layer.py 6개. 전체 130 통과 / 기존 실패 1개 그대로.
