# 2026-10-22

흰 바탕 PNG의 유테 칼선이 흰 캐릭터 얼굴을 가로질렀다(멍푸: "검정선 라인 밖으로 칼선 만들면 되는 기초적인 문제").
원인: 10/21에 넣은 여러 색 배경 분리(`scene_objects_mask`)가 흰 바탕 시트에도 들어갔다 -- 가장자리에 그림이 걸쳐
흰색이 90%에 조금 못 미쳤고, 색 경계 틈을 잇던 0.15mm 메우기가 얇은 검정 선을 넘어 흰 얼굴을 배경과 이었다.
고침:
  - 배경을 이어 붙일 때 그림 선을 넘지 않는다(메우기 삭제). 얇은 경계에 갇힌 배경 칸은 "거의 배경 색뿐인 조각"으로 뺀다.
  - 흰 바탕(가장자리 75% 이상이 한 색)은 유테·무테에서 같은 방식으로 -- 가장자리에서 배경을 채워 들어가되 선은
    넘지 않고(선의 0.3mm 미만 틈도 막음), 선으로 닫힌 흰 얼굴은 채운다. 칼선은 선 바깥으로.
  - 큰 판(그림의 25% 이상) 안에 따로 바탕이 있으면 그 안에서 한 번 더 찾는다(사진 속 투명 시트 등).
  - 흰 테두리 스티커 찾기가 그림의 85% 미만만 찾으면 그림 모양 기준으로.
확인(실제 그림, 프로그램 코드 그대로): 흰 바탕 캐릭터 -- 선 바깥 1.2mm. 여러 색 배경 그림 -- 3개 그대로.
스티커 시트 사진 3장(흰 테두리, 대리석·회색 바탕) -- 스티커마다 따로(43·39·50개).

같은 날 다시 점검(멍푸: "한번 더 점검해", "유테는 이미지 외곽에 선이 있는거야, 옅은 갈색 같은 색도 있으니 선을 기준으로",
"속도도 줄여"):
  - 흰 바탕에 그림이 가장자리까지 닿으면 흰색이 75%에 못 미쳐 여러 색 배경으로 잘못 갔다(멍푸 테이프 도안 흰 바탕
    버전으로 확인) -> 한 색 배경 기준 65%.
  - 그림 안 가는 흰 선이 그림 끝까지 닿으면(모자의 흰 격자) 배경이 스며들어 그림이 조각났다(무테 20개) -> 1mm 미만
    흰 길로는 배경이 들어가지 않게(6개, 투명 원본은 4개 -- 차이는 외곽선 없는 흰 부분이 바탕과 같은 색이라 구분 불가).
  - 옅은 갈색 외곽선도 검정 선과 똑같이 선 바깥으로(테스트 추가).
  - 속도: 색 거리 계산을 OpenCV로, 조각별 계산은 한 번에 -- 시트 사진 1.15초 -> 0.3초, 4373x2956 시트 2초.
    (비슷한 배경 색을 하나로 묶는 것도 해 봤으나 스티커가 붙어 칼선 수가 줄어(43->39) 뺐다.)
