# 2026-09-29 개발 일지

## 오늘 한 일

멍푸: "직접 프로그램 사용하면서 테스트 파일들의 원본 칼선과 비교하면서 칼선이 어디에 위치
해야 하는지, 왜 중첩되면 안 되는지. 그리고 프로그램 상용화를 위해 이번 주에 프로그램 결함을
해결해야 해" -- 사용 방식은 "멍푸 PC에서 직접 조작", 우선순위는 "칼선 위치·중첩 먼저".

1. **멍푸 PC에서 실제로 프로그램 사용**
   - 실제 창을 띄워 테스트 폴더의 격자 파일을 열고, "아니오(도무송 없음) → 자동으로 여러 개
     인식"과 "예(도무송 있음) → ① 인식 → 카드 칸 표시 → ② 도무송 직사각 → ③ 나머지" 두 흐름을
     끝까지 사용해 SVG로 내보낸 뒤, 그 SVG를 원본 칼선 레이어와 겹쳐 비교함.
   - 실제 PC 결과가 작업 공간의 자동 대조 결과와 같은 수치로 나와(무테: 매칭 56/57, IoU 0.90),
     나머지 파일은 작업 공간에서 같은 코드로 빠르게 대조함.

2. **원본 칼선 측정: 위치와 간격 원칙** (docs/개념정리.md 0-4에 표로 정리)
   - 칼선 레이어가 있는 8개 파일 전체에서 칼선끼리 교차 0건, 칼선 안의 칼선 0건.
   - 가장 가까운 두 칼선 간격 1.98~4.57mm(대부분 2.5mm 이상) -- 인쇄소 가이드 최소 2mm와 일치.
   - 중첩 금지 이유: 교차하면 떼는 순간 옆 스티커가 같이 잘려 둘 다 불량, 칼선 안의 칼선은
     가운데가 떨어짐, 2mm보다 좁으면 떼는 여백이 끊어지고 도무송 목형을 만들 수 없음.

3. **실제 사용 중 찾은 결함과 수정**
   - **무테+유테 자동에서 테두리 없는 캐릭터가 유테로 잘림(배경까지 칼선)**: "사각형이 아니면
     유테" 경로가 흰색/검은색 테두리 검사를 건너뛰고 있었음 → 어떤 경로든 테두리 선이 있을
     때만 유테. 한 파일 ①②③ 결과가 IoU 0.79/경계차 1.04mm → 0.91/0.54mm, 57개 전부 매칭.
   - **한 덩어리 그림이 칼선 2개로 갈라짐**: 매트 위에 누운 캐릭터(분할 단계에서 캐릭터 몸을
     배경으로 빼먹어 U자 → 안쪽으로 줄이며 두 조각), 펼친 책(책등 선으로 박스 2개) → 배경
     채우기로 구한 "배경이 아닌 덩어리"로 빠진 부분을 메우고, 넓게 붙은 박스는 합침(얇은
     줄기로만 닿은 꽃과 잎은 따로).
   - **90도 돌린 칸에서 배경 띠가 칼선에 들어감**: 칸 가장자리 몇 px가 테두리 선이라 배경
     채우기 출발점이 모두 막혀 있었음 → 출발점을 같은 색일 때만 안쪽으로 옮김. 또 다른 칸에서
     배경으로 확인된 색은 한쪽 가장자리에만 닿아도 배경으로 인정.
   - **칼선끼리 교차·이중 칼선·2mm 미만**: 저장 전 점검 도구를 만들어 돌려보니 무테+유테 자동과
     ①②③에서 교차 최대 9곳, 이중 칼선 최대 13곳, 2mm 미만 최대 11곳이 나왔음 → 모든 자동
     흐름에서 겹치거나 안에 들어간 칼선은 합치고, 2mm 미만은 작은 쪽을 2mm 떨어지게 줄임.
     수정 후 6개 격자 파일 × 3가지 흐름 전부 교차·이중·2mm 미만 0곳.
   - **저장 직전 점검**: SVG 내보내기 전에 위 세 가지를 검사해 남아 있으면 위치(mm)와 함께 알리고
     저장할지 물음(core/cut_check.py).
   - **칼로 자를 수 없는 가는 조각**(평균 폭 0.5mm 미만) 제거.
   - **화면**: "예/아니오(도무송)" 버튼이 무엇을 골랐는지 표시되지 않던 것 → 고른 쪽만 강조,
     좁은 화면에서 글자가 잘리던 것 → 짧은 문구. 결과 문구 "8개 중 57개"처럼 말이 안 되던 것 →
     "칼선 N개를 추가". "누적 초기화"가 확인 없이 전부 지우던 것 → 한 번 확인.

   - **①(도무송 있음 흐름)에서 맨 아래 빈 띠 칸에 사각형 칼선**: 수정본으로 PC에서 다시 사용하다
     발견 -- ①의 빈 칸 거르기가 자동 인식보다 느슨했음 → 같은 기준으로 거름.

4. **수정본으로 멍푸 PC에서 다시 사용**: 격자D 파일을 "예, 있음" → ① → 카드 칸 표시 → ②
   직사각 → ③ → 저장. 결과 매칭 78/85, IoU 0.92, 경계차 0.51mm, 칼선 교차·이중 0, 가장 가까운
   두 칼선 2.23mm(저장 전 점검 창 안 뜸 = 문제 없음). "예, 있음" 강조 표시, "칼선 87개를
   추가" 문구 확인. 이때 빈 띠 칸 문제를 찾아 위와 같이 고침.

7. **멍푸 피드백: 체크한 칼선 통과 불가 -- "칼선이 부드럽지 않고 너무 좁은 영역을 칼선을 생성했어"**
   (격자D 파일, PC 미리보기 300% 화면: 씨앗·체크무늬 소품·초콜릿·꽃·모자 쓴 캐릭터 아래쪽)
   - 원인: 이 시트는 요소마다 크림색 테두리 띠(폭 약 1.5~3mm)가 있고 원본 칼선은 몸통에서 약
     0.5~1mm 바깥(띠 안)인데, 우리는 (1) 띠가 배경과 비슷해 몸통만 잡고 거기서 1.2mm 안쪽을
     잘랐고(초콜릿·체크무늬), (2) 선으로만 그린 씨앗은 선 사이 좁은 틈만 잡았고, (3) 큰 이웃
     박스가 작은 소품의 띠를 덮어 띠가 잘렸고, (4) 요소 박스 경계에서 실루엣을 잘라 모자 쓴
     캐릭터 아래가 일자가 됐다.
   - 수정: 몸통 바로 바깥의 한 가지 밝은 띠가 일정 폭 안에서 끝나면 그 띠까지 그림으로 넣음(띠가
     안 끝나면 = 배경이라 넣지 않음). 실루엣 가장자리에 밝은 띠가 있으면 칼선을 띠 한가운데에
     두고(1.2mm 대신 띠 폭의 절반, 최소 0.5mm), 띠 안에서만 오목한 홈을 2mm 반경으로 메워
     부드럽게. 내 실루엣 2.5mm 안쪽 띠는 이웃 박스와 겹쳐도 번짐으로 인정. 박스 경계 자르기는
     3mm 넓혀서.
   - 결과(격자D): 무테·무테+유테 자동·①②③ 모두 원본 85개 전부 매칭(이전 78), 누락 0, 우리만 0,
     IoU 0.90, 경계차 0.42~0.45mm, 교차·이중·2mm 미만 0. 다른 격자 파일 수치는 그대로.

     줄바꿈. 드롭다운 "✕ 선택 해제"가 맨 위에 생기면 옵션이 한 줄씩 밀려 다른 옵션이 골라짐 -> 맨

     문구에 긴 경로/오류 원문 -> 경로는 파일 이름만, 90자(아래 칸 240자) 넘으면 "…". 좁은 창에서
