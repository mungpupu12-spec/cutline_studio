### 0-1. 작업 종류별: 개념 · 칼선 위치 · 선 개수 · 간격

모든 수치는 테스트 폴더 실제 완성 파일의 칼선레이어(작가 손 칼선)를 읽어 대조한 값입니다.

| 작업 종류 | 단위 | 칼선 위치 | 선 | 간격(기본 / 최소) |
|---|---|---|---|---|
| **무테** (자동 인식) | 칸 안의 **요소마다**(캐릭터·소품) | 요소 실루엣에서 **안쪽** — 배경은 스티커에 안 들어감 | 칼선 1개 | 1.2mm / 0.5mm (실측 0.7~1.5mm 안쪽) |
| **무테** (수동 드래그) | 선택한 영역 | 색 경계 추적 모양(영역을 거의 채우면 사각형)에서 안쪽 | 칼선 1개 | 1.2mm / 0.5mm |
| **유테** / **키스컷 마스킹테이프 모티프** | 칸 안 낱개 요소 | 실루엣(GrabCut)을 따라 **바깥쪽** | 칼선 1개 | 1.2mm / 0.5mm |

| **도무송** (원/타원/정사각/직사각/완칼) — 수동 선택, ② 표시한 칸, 자동 인식(칸 단위) | 선택 영역 / 칸(카드) 하나에 도형 하나 | 이미지 외곽 **안쪽**: 칼선은 이미지 외곽에서 블리딩 폭(기본 3mm, 최소 2.0mm) 안쪽에 들어가는 가장 큰 도형, 블리딩은 그 바깥 이미지 외곽까지 | 칼선 + 블리딩 (세이프티 선 없음) | 실측 카드 칸 2.8~3.3mm 안쪽 — 직사각 결과가 실제 칼선과 IoU 0.98~0.996 |
| **조각 스티커** | 이미지 전체 또는 선택 요소 | 실루엣 바깥쪽 | 세이프티 + 칼선 + 블리딩 | 각 단계 최소 2.0mm |
| **롤 전체 테두리** (마스킹테이프) | 롤 전체 내용 | 내용 사각형 바깥쪽, 이미지 경계 안 | 3단 | 최소 여유 2.0mm |

- **무테 = 이미지(요소) 안쪽, 배경색은 칼선이 되지 않음** (멍푸: "무테는 이미지 안쪽에 칼선이
  들어간다", "배경색이 칼선으로 잡히면 안 됨", "테스트 칼선 보면서 대조해"). 실제 손 칼선은
  무테 시트에서 요소마다 따로, 요소 실루엣 약 1mm 안쪽이었음. 서로 겹쳐 그려진 요소는 칼선이
  교차하지 않게 한 조각으로 합침. 안쪽으로 줄이면 사라질 만큼 가는 선 장식은 칼선을 만들지
  않고 알림(배경을 자르지 않기 위해).
- **도무송 = 이미지 안쪽** (멍푸: "도무송 직접 선택 후 칼선 종류에 따라 이미지 안쪽으로 칼선
  생성"). 최소 여유 2.0mm는 53차 인쇄소 가이드 실측값(상수 변경이 빠져 15mm로 남아 있던 것을
  9/28 바로잡음).
- **배경뿐인 칸**(이웃 칸 테두리 선이 살짝 걸친 빈 칸 포함)은 어떤 작업이든 칼선 대상에서 뺌.

### 0-2. 모든 작업에 공통

- **칼선은 절대 교차하거나 겹치지 않음, 칼선 사이 최소 2mm** (9/29 실측 근거는 0-4):
  서로 다른 요소의 칼선은 각자 유지하되, 겹치거나 안에 들어간 칼선은 한 조각으로 합치고
  (무테·무테+유테 자동·①②③의 ③), 2mm보다 가까운 두 칼선은 작은 쪽을 2mm 떨어지게 살짝 줄임.
  저장(SVG 내보내기) 직전에 한 번 더 점검해 남은 곳이 있으면 위치와 함께 알리고 저장할지 물음.
- **한 덩어리 그림은 칼선 하나**: 펼친 책(가운데 선), 매트 위에 누운 캐릭터처럼 넓게 붙은
  그림은 합쳐서 하나. 얇은 줄기·꼭짓점으로만 닿은 요소(꽃과 잎 등)는 따로.
- **칸/이미지 밖으로 안 나감**.
- **매끄럽게**: 유테는 여백의 10배로 다듬음. 무테(안쪽)는 요철 끝을 깎는 방식(여백의 2.5배,
  조각 크기의 0.4배 상한)으로 다듬어 그림 밖으로 절대 안 나감.
- **반복 도안**: 대표 하나만 실제로 추적하고 나머지는 칸 크기에 맞춰 복제.
- **얇은 배경 틈은 요소가 아님**: 폭이 칸 짧은 변의 2% 미만이면서 4:1 이상 길쭉한 조각.

### 0-3. 보조 기능 (9/28)

- **보조 탐지(자동 적용: 무테, 무테+유테 자동, ①②③의 ③)**: 기존 요소 탐지(선 기준 + GrabCut)가 놓친 요소만, 칸 가장자리
  배경색에서 이웃 픽셀을 따라 채우는 "배경 채우기" 방식으로 찾아 더함(칸 넓이 1% 이상, 기존
  칼선과 30% 이상 겹치면 제외). 실제 손 칼선 대조: 파스텔톤 시트 맞은 칼선 16/85 → 63/85,
  다른 시트는 그대로 또는 소폭 개선. 6개 격자 파일 합계 331/433 → 384/433.
- **의심 영역 경고 + "이 위치로 이동"**, **"힌트로 보정"(GrabCut 트라이맵)**: 무테·유테·마스킹
  테이프 자동 인식 결과에서 초록(캐릭터)/빨강(배경) 점으로 다시 계산, 같은 반복 칸에 자동 적용,
  빠진 요소는 새로 추가(이미 칼선이 있는 부분은 빼서 이중 칼선 방지). 무테는 보정 결과도 안쪽.
- 항목별 경고(겹친 조각 등)가 자동 인식 결과 창에 안 뜨던 버그 수정.

### 0-4. 칼선 위치와 간격 원칙 — 실제 손 칼선 측정값 (9/29)

테스트 폴더의 완성 파일 8개(칼선 레이어가 있는 것)를 전부 측정한 값입니다.

| 항목 | 실측 | 프로그램 규칙 |
|---|---|---|
| 칼선끼리 교차 | 0건 (8개 파일 전체) | 생기면 합침 + 저장 전 경고 |
| 칼선 안의 칼선(이중 칼선) | 0건 | 생기면 합침 + 저장 전 경고 |
| 가장 가까운 두 칼선 간격 | 1.98~4.57mm (대부분 2.5mm 이상) | 2mm 미만이면 작은 쪽을 줄여 2mm 확보 + 저장 전 경고 |
| 무테 요소 칼선 위치 | 요소 실루엣 약 0.7~1.5mm 안쪽 | 1.2mm 안쪽 |
| 카드(액자형) 칸 | 이미지 외곽 2.8~3.3mm 안쪽 사각형 | ② 도무송 직사각, 3mm 안쪽 |
| 흰 테두리 스티커(유테) | 테두리 바깥쪽 | 흰색/검은색 테두리 선이 있을 때만 바깥 1.2mm |

**왜 겹치면 안 되는가**
1. 칼날이 같은 자리를 두 번 지나가거나 선이 교차하면 그 자리의 스티커가 조각나거나 찢어짐 —
   한 스티커를 떼면 옆 스티커 모서리가 같이 잘려 나가 둘 다 불량.
2. 칼선 안에 또 칼선이 있으면(이중 칼선) 스티커 가운데가 따로 떨어짐.
3. 칼선 사이가 너무 좁으면 떼어내는 여백이 가늘어 떼다가 끊어지고, 도무송 목형은 칼날끼리 너무
   가까우면 만들 수 없음(인쇄소 가이드 최소 2mm).

**배경은 칼선에 들어가지 않음**: 칸 가장자리의 배경색(줄무늬·하늘·잔디 등)에서 채워 들어가
"배경이 아닌 곳"만 그림으로 봄. 90도 돌려 놓은 칸처럼 배경 띠가 한쪽 가장자리에만 닿는 경우를
위해 같은 시트의 다른 칸에서 배경으로 확인된 색도 배경으로 인정(9/29).

### 0-5. 알려진 한계 / 남은 결정

1. **카드 칸(한 장짜리 액자형 칸)**: 무테 자동 인식은 칸 안을 요소로 나누므로, 칸 전체를 한
   장으로 잘라야 하는 카드 칸은 ①②③ 경로에서 ②로 표시해 도무송(직사각)으로 만드는 흐름.
2. 파스텔톤 시트는 보조 탐지 후에도 칼선 85개 중 약 22개를 아직 못 찾음 — 대부분 꽃에 붙은 가는 잎
   (꽃+잎이 한 칼선이 되거나 잎이 빠짐)과, 배경과 거의 같은 연회색 테두리 띠를 가진 큰 캐릭터
   (실제 칼선은 띠 안쪽, 몸통에서 약 2.9mm 바깥인데 프로그램은 몸통 안쪽을 자름). "힌트로 보정"으로
   고칠 수 있음.
3. 무테/유테 자동 판정: 예전엔 배경 위에 떠 있는 요소를 전부 유테로 판정해 무테 시트가 바깥으로
   잘렸음(실제와 경계 2.9mm 차이) → 흰색/검은색 테두리 선 유무로 판정하도록 바꿈(무테 시트 경계차
   1.0mm, 흰 테두리 스티커 시트 0.56mm). 무테 작업을 직접 고르면 더 정확함(0.43mm).
4. 수동 무테 드래그로 여러 요소를 한 번에 고르면 예전 요청대로 "그룹 스티커"로 남음.

## 1. 가장 기본이 되는 원리

> "도안 하나에 외곽선 하나를, 그 이미지의 실제 모양(옵션)에 맞춰 만드는 것."

칼선(cutline)은 세 가지를 한 번에 정하는 일입니다.

1. **어디를 따라 자를 것인가** — 캐릭터의 실제 윤곽을 따라갈지, 셀(칸) 사각형을 그대로 쓸지,
   원/타원/사각형 같은 정해진 도형을 씌울지.
2. **얼마나 여유를 두고 자를 것인가** — 도안 가장자리에서 몇 mm 떨어진 곳에 선을 그릴지.
3. **몇 겹으로 그릴 것인가** — 선 하나만 그릴지, 세이프티·칼선·블리딩 3겹을 다 그릴지.

이 세 가지를 정하는 방식이 "작업 종류"(2번)와 "이미지 스타일"(3번)입니다.

## 2. 이미지 스타일 — 유테 / 무테

캐릭터·도안 하나하나가 **원래 그려진 방식** 자체를 가리킵니다. 인쇄되기 전부터 정해져 있는
성질이라, 도구가 마음대로 바꿀 수 없고 "이미 그렇게 그려진 그림"에서 읽어내는 것입니다.

| | 유테 (有테) | 무테 (無테) |
|---|---|---|
| 뜻 | 테두리(외곽선)가 **있음** | 테두리가 **없음** |
| 실제 그림 특징 | 캐릭터 몸 바깥에 일정한 두께의 흰색/검은색 테두리 선이 이미 그려져 있음(흔한 "상업 굿즈" 느낌) | 작가님 본인 그림체처럼, 테두리 없이 배경까지 칸을 꽉 채우는 연속된 그림 |
| 칼선을 만드는 방법 | 실제 실루엣(테두리 바깥쪽 끝)을 그대로 추적한 뒤, 그 모양을 **바깥쪽으로** 여백만큼 넓힘 | 원래는 셀/선택 사각형을 그대로 **안쪽으로** 여백만큼 줄이기만 함(도안 내용을 보지 않는 게 원래 정의) |
| 여백 방향 | 바깥쪽(도안보다 살짝 크게) | 안쪽(선택 영역보다 살짝 작게) |

### 2-1. 자동 판정 (사각형도 + 할로 우선 판정)

사람이 매번 눈으로 봐서 고르지 않아도 되게, 도구가 자동으로 유테/무테를 구분해주는 기능이
있습니다. 두 단계로 판정합니다.

1. **할로(배경 여유) 우선 확인** — 실제로 잘라낸 도안 내용이 선택 영역 사방 어디에도 거의 닿지
   않고 진짜 배경 여유(halo)를 두고 놓여 있으면, 모양이 얼마나 각져 보이든 상관없이 **유테**로
   판정합니다(작은 액자형 장식이 사각형에 가까워서 무테로 잘못 판정되던 실제 오류를 이렇게
   고쳤습니다).
2. **사각형도(rectangularity) 점수** — 할로가 없으면(내용이 선택 영역 가장자리에 닿아 있으면),
   "잘라낸 모양의 넓이 ÷ 그 모양을 감싸는 최소 회전 사각형의 넓이"를 계산합니다. 이 값이
   **0.85 이상**이면 무테(이미 사각형/틀에 가까운 형태), 아니면 유테로 판정합니다.

이 점수는 실제 파일의 실제 손그린 칼선으로 검증한 값입니다 — 자유롭게 움직이는 캐릭터는
0.55~0.79, 이미 틀에 맞춰 그려진 장식/액자형 도안은 0.879~1.000으로 뚜렷하게 갈립니다.

**알려진 한계**: 배경색과 도안 색의 대비가 약하면(예: 연한 색 배경의 액자형 도안), 이 자동 판정이
틀릴 수 있습니다. 이 경우 화면에 판정 근거(사각형도 수치)가 함께 보이므로 사람이 직접 바로잡을
수 있습니다.

### 2-2. 무테의 "색 경계 추적" (2026-09-08 도입, 2026-09-09 개선)

원래 무테는 선택 사각형을 그대로 줄이기만 했는데, "무테 칼선은 요소의 외곽 색을 기준으로 라인을
생성하고, 그 라인을 축소해 칼선을 만들어라"는 피드백으로 다음 규칙이 추가됐습니다.

- 선택 영역 안의 실제 선/색 경계를 먼저 추적합니다(GrabCut이 아니라 Canny 엣지 기반).
- 여러 요소(캐릭터 여러 마리 + 소품)가 서로 떨어져 있으면, 전부 하나로 이어 붙여("그룹 스티커")
  하나의 모양으로 만듭니다.
- **다만 추적된 모양이 선택 영역 사방 중 한 면이라도 가장자리에 거의 닿아 있으면**(=진짜 배경
  까지 채우는 연속 무늬 — 원래 무테의 정의 그 자체), 추적 결과를 버리고 다시 사각형 자체를
  안쪽으로 줄입니다. 이 판정을 안 하면, 캐릭터+장식이 셀 가장자리까지 흩어진 시트에서 지그재그로
  지저분한 칼선이 나오는 실제 문제가 있었습니다(2026-09-09에 실제 화면으로 확인/수정).
- 추적할 경계가 아예 없으면(빈 칸이거나 완전히 균일한 무늬) 그냥 사각형 축소로 안전하게 돌아갑니다.

이 판정 기준이 정확히 어디서 갈리는지: **선택 영역 사방 전부에 실제 배경 여유(halo)가 있으면 추적,
한 면이라도 없으면 사각형 축소**입니다.

## 3. 작업 종류 — 무테 / 유테 / 도무송 / 조각 스티커 / 키스컷 마스킹테이프

화면에서 맨 처음 고르는 "무엇을 만들 것인가"입니다. 2번(이미지 스타일)과 이름이 겹치는 두 가지
(무테/유테)가 있는데, 여기서는 그 스타일을 **그대로 작업 종류로도 쓴다**는 뜻입니다.

| 작업 종류 | 뭘 하는가 | 생성되는 선 | 필요한 선택 |
|---|---|---|---|
| **무테** | 셀 사각형(또는 색 경계 추적 결과)을 안쪽으로 줄임 | 칼선 1단만 | 도안 안 셀/영역 드래그 |
| **유테** | 실제 캐릭터 실루엣을 바깥쪽으로 늘림 | 칼선 1단만 | 캐릭터 하나 드래그 |
| **도무송** | 정원형/타원형/정사각형/직사각형/완칼(실루엣) 중 원하는 도형을 씌움 | 세이프티+칼선+블리딩 3단 | 영역 드래그 + 도형 선택 |
| **조각 스티커** | 이미지 전체(또는 선택한 요소 하나)의 실루엣을 그대로 추적 | 세이프티+칼선+블리딩 3단 | (선택 없으면 전체 이미지) |
| **키스컷 마스킹테이프** | 개별 모티프는 유테와 완전히 동일하게 처리 + "롤 전체 테두리 추가" 버튼으로 롤 전체 폭을 정의하는 테두리를 별도로 한 번 추가 | 모티프별 칼선 1단 + (선택 시) 롤 테두리 3단 | 모티프 하나 드래그 (+ 필요시 롤 테두리 추가) |

**참고 -- 이름이 헷갈리기 쉬운 부분**: "완칼"이라는 말은 두 군데서 쓰입니다. 도무송 안의 재단
도형 선택지 중 하나(실루엣 그대로, 다이 없이 자유형으로 자름)를 "완칼(실루엣)"이라고 부르고,
예전에는 작업 종류 이름 자체도 "완칼"이었지만 지금은 "조각 스티커"로 이름이 바뀌었습니다(뜻은
그대로, 화면에 보이는 이름만 더 쉬운 말로 바뀜).

### 3-1. 여러 작업을 한 파일에 누적하기

드래그 → 작업 종류 선택 → "이 영역 추가 + 미리보기"를 반복하면, 매번 만든 결과가 계속 쌓입니다
(대체가 아니라 누적). 서로 다른 작업 종류로 만든 결과라도 전부 같은 파일에 합쳐지고, 합쳐진
뒤에는 서로 다른 요소끼리도 다시 한번 최소 간격(아래 4번)을 확인해 너무 가까우면 자동으로
합칩니다. 새 파일을 열거나 시트를 새로 합성하면 이전 누적은 자동으로 초기화됩니다(다른 이미지의
좌표가 섞이면 안 되므로).

### 3-2. "자동으로 여러 개 인식 + 추가"

한 시트 안에 같은 작업 종류로 만들 요소가 여러 개 있을 때, 하나씩 드래그하지 않고 시트 전체를
한 번에 훑어 전부 찾아 자동으로 추가하는 기능입니다. 실제 시트가 격자(그리드)로 나뉘어 있으면 그
격자 칸을 그대로 쓰고, 아니면 색/선 경계로 요소를 하나씩 찾아냅니다.

**주의(2026-09-09 이전 실제 회귀 이력)**: 한때 이 기능이 각 칸 안의 캐릭터+소품을 다시 잘게
쪼개려고 시도한 적이 있었는데, 실제 파일로 검증한 결과 정상적인 "카드형" 디자인(캐릭터+소품+
글자박스가 함께 있는 한 칸)까지 잘못 쪼개버리는 심각한 문제가 있어서 그 세부 쪼개기 기능은
완전히 되돌렸습니다(관련 함수는 남아있지만 자동으로 호출되지 않음). 지금은 격자 칸 자체를 그대로
하나의 단위로 인식합니다.

## 4. 여백/간격 기준값 — 실제 파일로 검증한 숫자들

| 이름 | 값 | 어디에 쓰이나 | 근거 |
|---|---|---|---|
| `DEFAULT_STYLE_MARGIN_MM` | **1.2mm** | 무테/유테 단일 여백 기본값 | 키스컷 마테 좋은 예/나쁜 예 실측(좋은 예 평균 1.19mm) + 2026-09-09 마스킹테이프/리무버블 스티커 8개 실물 재검증에서도 일치 |
| `MIN_STYLE_MARGIN_MM` | **0.5mm** | 위 여백의 절대 최소값(이보다 작게 입력해도 자동으로 이 값까지 올림) | 실제 파일들에서 가장 좁았던 정당한 여백(텍스트 라벨류 0.55mm대)보다 살짝 낮게 여유를 둔 값 |
| `MIN_GAP_MM` | **2.0mm** | 서로 다른 요소(또는 세이프티/칼선/블리딩 각 단계) 사이 강제 최소 간격 -- "그 어떤 법칙보다 우선" | 인쇄/커팅 밀림 시에도 옆 요소를 잘라먹지 않기 위한 실무 규칙. 2026-09-09 도무송 폼파일 실측(실제 다이 간 최소 간격 2.34mm)으로도 안전한 하한선임을 재확인 |
| 세이프티/칼선/블리딩 기본값 | **1.0 / 2.0 / 3.0mm** | 도무송·조각 스티커의 3단 간격 기본값 | `OffsetSpec` 기본값, 각 단계는 항상 `MIN_GAP_MM` 이상씩 벌어지도록 자동 보정됨 |
| 마스킹테이프 벤더 안전여백 | **1.5mm** | 15mm 롤 기준, 롤 위/아래 각각의 벤더 표준 인셋 | 2026-09-09 마스킹테이프 실물 참고 파일 2개에서 동일하게 확인 |
| 밀림 예상 여백(`slip_margin`) | 기본 1.5mm + (실측 편차 × 1.0) | 반복 배치되는 시트에서, 실제 손그린 칼선의 편차를 근거로 여백을 더 얹을 때 | 안전 배율(`DEFAULT_SAFETY_FACTOR`)은 실제 파일로 검증해 2.0 → 1.0으로 낮춤(처음 값이 과했음) |

재검증했는데, 위 숫자들이 전부 그대로 안전하고 정확했습니다. 그래서 이번에는 숫자를 바꾸지 않고
"이미 맞다"는 것만 다시 확인했습니다.

## 6. 도구 자체의 안전장치들

지금까지 실제로 문제가 됐던 경우를 겪고 나서 하나씩 추가된, "조용히 틀려버리지 않게" 막는
장치들입니다.

1. **슬롯 자동 축소는 기본 꺼짐** — 시트 합성 시 도안이 슬롯보다 크면 기본은 위반만 보고하고,
   조용히 줄이지 않습니다(줄이면 인쇄 품질 문제로 이어질 수 있음). 켜서 쓰면 축소 전/후 크기와
   비율을 항상 같이 보여줍니다.
2. **정밀도(업샘플) 자동 조정** — 이미지가 아주 크면 처리 속도 보호를 위해 정밀도를 자동으로
   낮추되, 지금까지 실제로 다룬 파일 크기(4500px대)까지는 전혀 영향 없이 항상 최고 정밀도(4배)를
   유지합니다.
3. **여백 최소값 보호** — 무테/유테 여백을 0이나 너무 작은 값으로 입력해도 `MIN_STYLE_MARGIN_MM`
   (0.5mm)까지 자동으로 올리고, 그 사실을 항상 알려줍니다.
4. **무테 선택 영역이 그림보다 타이트한 경우 경고** — 무테가 사각형 축소로 처리될 때, 계산된
   칼선이 실제 그림 안쪽으로 파고들면 경고를 남깁니다(추적 경로를 탄 경우는 정의상 발생할 수
   없어 이 검사를 하지 않음).
5. **최소 간격(2mm) 강제** — 서로 다른 요소끼리, 그리고 누적된 서로 다른 작업 종류끼리도 항상
   최소 2mm 이상 떨어지도록 자동으로 합칩니다.

## 7. 파일 입출력

- **입력**: 어도비 일러스트(.ai, PDF 호환) 파일이 기본, PNG/JPG도 가능. .ai 안에 이미 심겨 있는
  실제 인쇄용 이미지를 원본 해상도 그대로 추출해서 쓰고(다시 렌더링하지 않아 화질 손실 없음),
  심겨 있는 이미지가 없는 순수 벡터 파일이면 지정한 DPI로 페이지를 래스터화합니다.
- **출력**: SVG로 내보내기(레이어별 이름/색상 유지), 또는 기존 .ai 파일에 원본을 전혀 건드리지
  않고 칼선만 새 레이어("칼선레이어_자동생성" — 작가님의 실제 손그린 레이어 이름과 절대 겹치지
  않게 구분된 이름)로 추가.
- **가이드 + 여러 도안 → 시트 합성**: 가이드 파일(재단/칼선/슬롯 배치 정의) + 도안 여러 장을
  넣으면 슬롯에 맞춰 자동으로 배치한 시트 이미지를 만들고, 그 결과가 그대로 "도안 파일" 입력이
  되어 이후 전 과정이 파일 하나 작업할 때와 동일하게 진행됩니다.

## 8. 라이선스 시스템 (개인/기업)

- 개인 라이선스는 여러 기기에서 써도 막지 않고 기록만 하고, 기업 라이선스는 계약된 좌석 수를
  넘는 기기가 접속하면 그 즉시 전체를 잠급니다(재활성화 코드로 풀림).
- 서명은 비대칭키(Ed25519)라 앱 안에 들어 있는 공개키로는 위조된 "유효함" 응답을 만들 수 없습니다.
- 실제 서버/관리자 도구/서명키는 공개 저장소(`cutline_studio`)와 완전히 분리된 별도 비공개
  저장소(`cutline_license`)에만 있습니다.
- 위반 적발 후 실제 인물/회사를 공개적으로 노출하는 기능은 명예훼손·초상권 문제로 번질 수 있어
  의도적으로 만들지 않았습니다 — 잠금과 활성화 기록(증거 자료) 확보까지만 지원하고, 그 이후는
  변호사와 상의해 정식 법적 절차로 진행하시길 권합니다.
