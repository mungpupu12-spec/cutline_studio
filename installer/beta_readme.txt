컷라인 스튜디오 베타 테스터 안내
================================

1. 설치
   - 받은 "컷라인스튜디오_베타_설치_날짜.exe"를 더블클릭하세요.
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] -> [실행]을 누르세요.
     (서명 인증서가 없는 베타 프로그램이라 뜨는 안내이고, 설치 파일 자체의 문제는 아닙니다.)
   - 관리자 권한 없이 내 사용자 폴더에 설치되고, 바탕화면과 시작 메뉴에 바로가기가 생깁니다.

2. 처음 실행
   - 받은 라이선스 키(CLS-PERS-로 시작)를 입력하고 [활성화]를 누르세요.
   - 인터넷에 연결되어 있어야 합니다. 서버가 쉬고 있으면 첫 연결에 최대 1분 정도 걸릴 수 있습니다.
   - 베타 테스터 키는 사용 기한이 없습니다. 다만 인터넷 연결 없이 쓸 수 있는 기간은 마지막 연결 후 3일입니다.

3. 새 버전 설치
   - 새 설치 파일을 그대로 실행하면 덮어써서 업데이트됩니다. 라이선스 키는 다시 넣지 않아도 됩니다.

4. 제거
   - 시작 메뉴 "컷라인 스튜디오" 폴더의 "컷라인 스튜디오 제거" 또는
     Windows 설정 -> 앱 -> 설치된 앱 -> "컷라인 스튜디오 (베타)"에서 제거하세요.

5. 문제가 생기면
   - 프로그램에서 생긴 오류는 자동으로 개발자에게 전달됩니다.
   - 화면을 캡처해서 함께 알려주시면 더 빨리 고칠 수 있습니다.
