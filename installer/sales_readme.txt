컷라인 스튜디오 사용 안내
========================

1. 설치
   - 받은 "컷라인스튜디오_설치_날짜.exe"를 더블클릭하세요.
   - "Windows의 PC 보호" 파란 창이 뜨면 [추가 정보] -> [실행]을 누르세요.
     (개인이 만든 프로그램이라 뜨는 Windows 안내이고, 설치 파일 자체의 문제는 아닙니다.)
   - 관리자 권한 없이 내 사용자 폴더에 설치되고, 바탕화면과 시작 메뉴에 바로가기가 생깁니다.

2. 처음 실행(라이선스 등록)
   - 구매할 때 받은 라이선스 키(CLS-로 시작)를 복사해 붙여 넣고 [활성화]를 누르세요.
   - 인터넷에 연결되어 있어야 합니다. 서버가 쉬고 있으면 첫 연결에 최대 1분 정도 걸릴 수 있습니다.
   - 라이선스는 사용 기한이 없습니다. 인터넷 없이 쓸 수 있는 기간은 마지막 연결 후 3일입니다.
   - 라이선스 키 하나는 컴퓨터 1대용입니다. 다른 컴퓨터에서 같은 키를 쓰면 키가 잠깁니다.
     컴퓨터를 바꿀 때는 문의해 주세요. 같은 컴퓨터에 다시 설치하면 키를 다시 넣지 않아도 됩니다.

3. 칼선 고치기
   - 미리보기 위 [🖊 칼선 수정]을 누르고 칼선을 클릭하면 기준점이 보입니다.
   - 점 끌기 = 모양 수정, 동그라미 핸들 끌기 = 곡선 조절(Alt를 누른 채 끌면 한쪽만),
     선 위 더블클릭 = 점 추가, 점 더블클릭 = 뾰족한 점/둥근 점, Delete = 점 삭제
     (점을 고르지 않고 Delete = 칼선 삭제), Ctrl+Z = 되돌리기.
   - "같은 그림 모두 적용"을 켜 두면 반복된 같은 그림의 칼선도 똑같이 고쳐집니다.

4. 새 버전 설치
   - 새 설치 파일을 그대로 실행하면 덮어써서 업데이트됩니다. 라이선스 키는 다시 넣지 않아도 됩니다.

5. 제거
   - 시작 메뉴 "컷라인 스튜디오" 폴더의 "컷라인 스튜디오 제거" 또는
     Windows 설정 -> 앱 -> 설치된 앱 -> "컷라인 스튜디오"에서 제거하세요.

6. 꼭 확인해 주세요
   - 칼선은 자동으로 만들어집니다. 인쇄소에 보내기 전에 반드시 직접 확인해 주세요.
